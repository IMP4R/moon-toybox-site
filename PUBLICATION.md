# Публичная версия Moon Toybox

Vite сохранён; публикация GitHub Pages из docs. Четыре объекта в демонстрации: moon, truck, teddy, knot.

Truck: Low poly Stylized Truck, dehariyalokesh1998, CC BY 4.0 — https://sketchfab.com/3d-models/0a78728c391044b29d06acc2d00ec87a . Включён с атрибуцией и описанием изменений.

Teddy: Low poly asset: Teddy Bear, Kieran H, Free Standard / NoAI — https://sketchfab.com/3d-models/83319efff3554750a08764fd7001c991 . Только рендеры в композиции сайта: исходник и SDF исключены, скачивание и копирование для него не предлагаются. В библиотеке moon, truck, knot.

npm ci; node package-public.mjs; npm run build. Оригинальный рабочий проект не изменяется.
